# FramePusher

Full-screen interactive toy. Nested frames cover the viewport, snapped to a grid of animated eyes.

## Play

- **Drag any frame** — push the others outward
- **Release** — frames stay where they are
- **Reset button** (bottom right) — springs everything back to center
- Eyes follow your cursor, glance at the green block randomly, and look surprised on bounce

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Stack

Vanilla JS · Canvas API · Vite
